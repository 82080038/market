METODOLOGI:
  1. Resampling: daily (harian), weekly (mingguan W), monthly (bulanan ME)
  2. Cross-Correlation Function (CCF):
     - Daily: lag -60 h +60 hari
     - Weekly: lag -8 h +8 minggu
     - Monthly: lag -3 h +3 bulan
  3. Granger Causality Test: F-test, lag order disesuaikan per frekuensi
  4. Rolling average: 7 dan 30 (daily), 4 dan 12 (weekly), 3 (monthly)
  5. Signifikansi: p-value < 0.05 (CCF atau Granger)
  6. Data alignment: linear interpolation + forward-fill

CATATAN & KETERBATASAN:
  - NDVI: data real dari Sentinel-2 via Microsoft Planetary Computer (gratis, no account)
    → Cloud cover threshold < 30%, 10m resolusi, 5-day revisit
    → Jika tidak ada scene yang valid, fallback ke simulasi
  - Nightlight: simulasi (VIIRS Earthdata credentials not configured)
    → Untuk data real: set EARTHDATA_USERNAME dan EARTHDATA_PASSWORD di .env
  - Hasil korelasi pada data simulasi TIDAK dapat diinterpretasikan sebagai
    bukti kausalitas nyata — hanya menguji metodologi pipeline
  - Untuk analisis produksi: integrasikan GEE dengan service account
  - Granger causality bukan bukti kausalitas sejati, hanya prediksi statistik
