## 1. Dua Sumber Utama Keuntungan

### 1.1 Capital Gain (Appreciation)

**Definisi:** Profit dari selisih harga jual dan harga beli saham.

```
Capital Gain = (Harga Jual - Harga Beli) × Jumlah Lembar - Biaya Transaksi

Contoh:
  Beli 1.000 lembar saham @ Rp5.000 = Rp5.000.000
  Jual 1.000 lembar saham @ Rp6.500 = Rp6.500.000
  Capital Gain = Rp1.500.000 (30%)
  Biaya transaksi ≈ Rp52.000 (0.4% × Rp13.000.000)
  Net profit ≈ Rp1.448.000 (28.96%)
```

**Karakteristik:**
- Tidak terjamin — tergantung pergerakan harga pasar
- Tidak realisasi sampai dijual (paper gain vs realized gain)
- Return historis IHSG: ~12-15% p.a. (jangka panjang)
- Volatilitas tinggi jangka pendek

### 1.2 Dividen (Income)

**Definisi:** Pembagian laba perusahaan kepada pemegang saham.

```
Dividen Yield = (Dividen per Saham / Harga Saham) × 100%

Contoh:
  Saham BBCA @ Rp8.000
  Dividen tahunan Rp320/lembar
  Yield = 320/8000 × 100% = 4.0%
```

**Karakteristik:**
- Cash flow rutin (biasanya tahunan atau semesteran di Indonesia)
- Tidak perlu menjual saham untuk mendapat income
- Lebih stabil daripada capital gain
- Dividen dapat di-reinvestasi (compounding)

### 1.3 Total Return

```
Total Return = Capital Gain + Dividen Yield

Contoh historis IHSG (10 tahun, 2014-2024):
  Capital appreciation: ~8% p.a.
  Dividen yield: ~3% p.a.
  Total return: ~11% p.a.
```

## 2. Persiapan Sebelum Mulai

### 2.1 Fondasi Finansial

Sebelum berinvestasi saham, pastikan fondasi finansial kuat:

```
Langkah 1: Lunasi utang berbunga tinggi (> 8% p.a.)
  ↓  Alasan: Return saham ~12% tidak menjamin, tetapi bunga utang 20% pasti
Langkah 2: Siapkan dana darurat (3-6 bulan pengeluaran)
  ↓  Alasan: Tidak terpaksa jual saham saat pasar turun
Langkah 3: Pastikan income stabil
  ↓  Alasan: Investasi saham butuh waktu, bukan tempat parkir dana urgent
Langkah 4: Tentukan timeframe (minimal 3-5 tahun)
  ↓  Alasan: Volatilitas jangka pendek tinggi, butuh waktu untuk compounding
Langkah 5: Gunakan uang dingin
  ↓  Alasan: Uang yang tidak dibutuhkan dalam waktu dekat
```

## 3. Strategi Investasi Jangka Panjang

### 3.1 Buy and Hold (Value Investing)

**Filosofi:** Beli saham berkualitas di harga wajar, tahan selama bertahun-tahun, nikmati compounding.

**Prinsip (Warren Buffett style):**
1. Beli perusahaan dengan **competitive advantage (moat)** yang tahan lama
2. Harga beli di bawah **intrinsic value** (margin of safety)
3. Tahan selama fundamental tidak berubah
4. "Time in the market > timing the market"

**Screener kriteria:**
```
✓ ROE > 15% (consistent 5+ years)
✓ D/E < 1.0 (low leverage)
✓ Revenue growth > 10% p.a.
✓ Free cash flow positive
✓ P/E < industry average
✓ Dividen konsisten (jika income strategy)
✓ Market cap > Rp 1 triliun (likuiditas)
```

**Contoh saham Indonesia (ilustratif):**
- BBCA — ROE ~35%, konsisten, blue chip
- UNVR — Consumer staple, moat kuat, dividen konsisten
- TLKM — Monopoly-like, dividen tinggi

**Expected return:** 12-15% p.a. (capital gain + dividen)
**Risk level:** Low-Medium
**Time commitment:** 2-4 jam/bulan (review berkala)

### 3.2 Growth Investing

**Filosofi:** Beli perusahaan dengan pertumbuhan tinggi, bahkan jika valuasi terlihat mahal.

**Prinsip (Philip Fisher / Cathie Wood style):**
1. Cari perusahaan dengan revenue/earnings growth > 20% p.a.
2. Sektor dengan tailwind (tech, green energy, healthcare)
3. Tidak harus profit sekarang, asalkan path to profitability jelas
4. Hold selama growth story intact

**Screener kriteria:**
```
✓ Revenue growth > 20% p.a.
✓ TAM (Total Addressable Market) besar
✓ Market leader atau disruptor
✓ Management visioner
✓ Scalable business model
```

**Expected return:** 15-25% p.a. (jika growth story terbukti)
**Risk level:** Medium-High
**Time commitment:** 4-8 jam/bulan

### 3.3 Dollar Cost Averaging (DCA)

**Filosofi:** Beli saham secara rutin dengan jumlah tetap, terlepas dari harga.

**Mekanisme:**
```
Bulan 1: Investasi Rp 1.000.000, harga Rp 5.000 → beli 200 lembar
Bulan 2: Investasi Rp 1.000.000, harga Rp 4.000 → beli 250 lembar
Bulan 3: Investasi Rp 1.000.000, harga Rp 5.500 → beli 182 lembar
Bulan 4: Investasi Rp 1.000.000, harga Rp 6.000 → beli 167 lembar

Total investasi: Rp 4.000.000
Total lembar: 799
Average price: Rp 5.006/lembar
```

**Keunggulan:**
- Eliminasi stress market timing
- Beli lebih banyak saat harga rendah
- Disiplin menabung dan berinvestasi
- Cocok untuk investor sibuk

**Kekurangan:**
- Kurang optimal di bull market berkelanjutan (lump sum lebih baik)
- Butuh disiplin untuk terus invest saat pasar turun

**Data:** Vanguard study menemukan lump sum investing beat DCA 68% of the time, tetapi DCA lebih baik secara psikologis untuk sebagian besar investor.

### 3.4 Index/ETF Investing

**Filosofi:** Tidak mungkin konsisten beat market, jadi ikuti indeks dengan biaya rendah.

**Data kunci:**
- 85-88% active fund managers underperform indeks dalam 15 tahun (SPIVA)
- S&P 500 return 30 tahun: ~10.4% p.a. (compound)
- Expense ratio index fund: ~0.03% vs active fund: ~0.32%

**Implementasi di Indonesia:**
- Beli reksa dana indeks (BI, SRI-KEHATI, LQ45)
- Atau beli ETF yang tercatat di BEI
- Atau beli top 10-20 saham IHSG dengan weight proporsional

**Expected return:** 10-12% p.a. (sebanding IHSG)
**Risk level:** Low
**Time commitment:** 30 menit/bulan

### 3.5 Dividend Investing

**Filosofi:** Beli saham yang membayar dividen konsisten dan growing, nikmati passive income.

**Strategi:**

| Sub-strategi | Target Yield | Target Growth | Contoh |
|---------------|-------------|---------------|--------|
| **Dividend Aristocrat** | 2.5-4% | 6-8% p.a. | BBCA, UNVR, TLKM |
| **High Yield** | 5-7% | 2-3% p.a. | PGAS, ITMG, INDY |
| **Dividend Growth** | 1-3% | 10%+ p.a. | Growth companies mulai dividen |

**Screener kriteria:**
```
✓ Dividen konsisten 5+ tahun
✓ Payout ratio < 70% (sustainable)
✓ Dividen growth > inflation
✓ Free cash flow cover dividen 1.2x+
✓ D/E < 1.5
✓ ROE > 12%
```

**Power of DRIP (Dividend Reinvestment):**
```
Modal awal: Rp 10.000.000
Yield: 4%
Dividen growth: 8% p.a.
Reinvestasi semua dividen

Tahun 1:  Yield 4% → Rp 400.000 → beli lebih banyak saham
Tahun 5:  Yield on cost ~5.9%
Tahun 10: Yield on cost ~8.7%
Tahun 20: Yield on cost ~18.9%
Tahun 30: Yield on cost ~42.4%

Total return (30 tahun): ~1.000%+ (10x modal awal)
```

**Expected return:** 8-11% p.a. (yield + growth)
**Risk level:** Low-Medium
**Time commitment:** 1-2 jam/bulan

## 4. Strategi Trading Jangka Pendek-Menengah

### 4.1 Swing Trading

**Definisi:** Tahan saham 2-14 hari, manfaatkan "ayunan" harga dari support ke resistance.

**Mengapa cocok untuk pemula:**
- Tidak perlu pantau pasar setiap jam
- Bisa sambil bekerja (review 1-2x sehari)
- Risk moderat (tidak seintens day trading)
- Profit per transaksi lebih besar dari scalping

**Setup:**
```
1. Pilih saham likuid (volume > 1 juta/hari, spread tipis)
2. Identifikasi trend (uptrend: HH + HL, di atas MA20/50)
3. Tunggu pullback ke support (MA20, Fibonacci 50%, previous resistance)
4. Entry: konfirmasi reversal (bullish candlestick, RSI turning up)
5. Stop loss: di bawah pullback low - 0.5 ATR
6. Target: swing high berikutnya atau measured move
7. Risk/Reward: minimal 1:2
```

**Contoh:**
```
Saham XYZ uptrend, harga Rp 5.000
Pullback ke MA20 di Rp 4.700
Entry: Rp 4.750 (konfirmasi bullish engulfing)
Stop loss: Rp 4.600 (di bawah pullback low)
Target: Rp 5.100 (previous swing high)

Risk: Rp 150/lembar
Reward: Rp 350/lembar
R/R = 1:2.3
Position size: Risk Rp 100.000 → 667 lembar (6 lot)
```

**Expected return:** 5-15% per bulan (jika konsisten)
**Risk level:** Medium
**Time commitment:** 1-2 jam/hari

### 4.2 Trend Following

**Filosofi:** "The trend is your friend" — beli saham yang sedang uptrend, jual saat tren berbalik.

**Aturan:**
1. Identifikasi uptrend (price di atas MA50, MA50 di atas MA200)
2. Entry saat pullback ke MA20 atau MA50
3. Exit saat price break di bawah MA50
4. Trailing stop: naikkan stop saat harga naik

**Golden Cross Signal:**
```
Golden Cross: MA50 cross ABOVE MA200 → sinyal BULLISH
Death Cross: MA50 cross BELOW MA200 → sinyal BEARISH
```

**Expected return:** 10-20% per tren (bisa beberapa bulan)
**Risk level:** Medium
**Time commitment:** 30 menit/hari

### 4.3 Breakout Trading

**Filosofi:** Beli saham yang baru menembus resistance penting dengan volume tinggi.

**Setup:**
```
1. Identifikasi consolidation pattern (box, triangle, flag)
2. Tunggu breakout dengan volume > 1.5x average
3. Entry: di breakout candle close atau next day open
4. Stop loss: just inside broken resistance (support baru)
5. Target: measured move (height of consolidation projected)
```

**Validasi breakout:**
```
✓ Volume > 1.5x 20-day average volume
✓ Close above resistance (bukan hanya spike)
✓ Market breadth mendukung (IHSG tidak turun tajam)
✓ Tidak ada news negatif yang kontradiktif
```

**Expected return:** 10-30% per breakout
**Risk level:** Medium-High (false breakout risk)
**Time commitment:** 1 jam/hari

### 4.4 Mean Reversion (Buy the Dip)

**Filosofi:** Saham berkualitas yang turun sementara akan kembali ke nilai wajarnya.

**Setup:**
```
1. Pilih saham blue chip dengan fundamental kuat
2. Tunggu harga turun 10-20% dari recent high (tanpa fundamental change)
3. Cek RSI < 30 (oversold)
4. Cek harga mendekati support kuat (MA200, previous low)
5. Entry: konfirmasi reversal candle
6. Target: kembali ke mean (MA50 atau pre-dip level)
```

**Kunci:** HANYA untuk saham dengan fundamental kuat. Jangan "buy the dip" pada saham yang turun karena fundamental berubah (fraud, kebangkrutan, regulasi).

**Expected return:** 5-15% per mean reversion cycle
**Risk level:** Medium
**Time commitment:** 1 jam/hari

### 4.5 Position Trading

**Definisi:** Tahan saham beberapa minggu hingga bulanan, manfaatkan tren besar.

**Perbedaan dengan swing trading:**
| Aspek | Swing Trading | Position Trading |
|-------|--------------|-----------------|
| **Durasi** | 2-14 hari | 1-6 bulan |
| **Target** | 5-15% per trade | 20-50% per trade |
| **Analisis** | Teknikal dominan | Teknikal + Fundamental |
| **Frekuensi** | 4-8 trade/bulan | 1-3 trade/bulan |
| **Monitoring** | 1-2x sehari | 2-3x seminggu |

## 6. Strategi Kombinasi (Layered Approach)

### 6.1 Five-Layer System

Untuk modal > Rp 50 juta, gunakan pendekatan berlapis:

```
Layer 1: Core Portfolio (50-60% modal)
  ├── Blue chip dividend stocks (hold 5+ tahun)
  └── Target: 10-12% p.a. (yield + growth)

Layer 2: Growth Allocation (15-20% modal)
  ├── Growth stocks dengan moat (hold 1-3 tahun)
  └── Target: 15-20% p.a.

Layer 3: Swing Trading (10-15% modal)
  ├── Swing trading saham likuid (2-14 hari)
  └── Target: 5-15% per bulan

Layer 4: Opportunistic (5-10% modal)
  ├── Buy the dip, breakout, special situations
  └── Target: variable, high risk

Layer 5: Cash Reserve (5-10% modal)
  ├── Kas/RD pasar uang untuk opportunity
  └── Target: liquidity, dry powder
```

## 8. Manajemen Risiko: Kunci Survival

Lihat `07-manajemen-risiko.md` untuk detail lengkap.

### 8.1 Aturan Emas

```
1. Risk per trade: MAX 1-2% dari total modal
2. Max single position: 10-20% dari portfolio
3. Max sector exposure: 30%
4. Stop loss: WAJIB di setiap posisi
5. Risk/Reward: MIN 1:2
6. Max open positions: 5-10 (tergantung modal)
7. Portfolio heat (total open risk): MAX 6-8%
```

### 8.2 Position Sizing

```python
def calculate_position_size(capital, entry, stop_loss, risk_pct=0.02):
    """Calculate position size based on risk percentage."""
    risk_amount = capital * risk_pct
    risk_per_share = abs(entry - stop_loss)
    if risk_per_share <= 0:
        return 0
    shares = risk_amount / risk_per_share
    # Round to lot (100 shares for IDX)
    lots = int(shares / 100)
    return lots * 100

# Contoh:
# Capital: Rp 50.000.000
# Entry: Rp 5.000
# Stop loss: Rp 4.800
# Risk: 2%
#
# Risk amount: Rp 1.000.000
# Risk per share: Rp 200
# Shares: 5.000
# Lots: 50
# Position value: Rp 25.000.000 (50% dari modal — terlalu besar!)
#
# Solusi: turunkan risk ke 1% atau perketat stop loss
```

### 8.3 Stop Loss Strategies

## 9. Kendala dan Cara Mengatasi

### 9.1 Kendala Psikologis

| Kendala | Dampak | Cara Mengatasi |
|---------|--------|----------------|
| **Loss aversion** | Hold loser too long, sell winner too early | Pre-defined exit rules, automated stop loss |
| **FOMO** | Beli di puncak karena takut ketinggalan | Tunggu pullback, jangan chase |
| **Panic selling** | Jual di lembah saat pasar turun | Investasi uang dingin, jangan over-leverage |
| **Overconfidence** | Overtrading, ignore risk | Track performance vs benchmark |
| **Herding** | Ikut-ikutan kerugian massal | Kontrarian thinking, analisis mandiri |
| **Anchoring** | Tidak cut loss karena anchored ke harga beli | Independent valuation, ignore entry price |
| **Recency bias** | Overweight event terbaru | Lihat data jangka panjang |

### 9.2 Kendala Pasar

| Kendala | Dampak | Cara Mengatasi |
|---------|--------|----------------|
| **Likuiditas rendah** | Sulit exit, slippage tinggi | Pilih saham dengan volume > 1 jlembar/hari |
| **Saham gorengan** | Harga naik tanpa fundamental, lalu anjlok | Hindari, fokus ke saham fundamental kuat |
| **Auto-reject** | Tidak bisa eksekusi saat harga di limit | Gunakan limit order, jangan market order di opening |
| **Free float rendah** | Harga mudah dimanipulasi | Cek HSC list, hindari saham konsentrasi tinggi |
| **Foreign outflow** | IHSG tertekan | Lihat foreign flow sebagai konteks, bukan sinyal tunggal |
| **Keterlambatan informasi** | Entry terlambat, harga sudah move | Gunakan multiple sumber, monitoring real-time |
| **Biaya transaksi** | Menggerus return | Minimalkan frekuensi trading, hitung total cost |

### 9.3 Kendala Eksternal

| Kendala | Dampak | Cara Mengatasi |
|---------|--------|----------------|
| **Fed rate hike** | Investor asing keluar, IHSG turun | Diversifikasi aset, hedge dengan SBN |
| **Geopolitik** | Risk-off sentiment | Cash reserve untuk buy the dip |
| **Krisis ekonomi** | Bear market, drawdown besar | Uang dingin, long timeframe, DCA |
| **Inflasi tinggi** | Daya beli turun, margin tergerus | Saham konsumer defense, komoditas |
| **Depresiasi Rupiah** | Emiten utang valas tertekan | Pilih emiten dengan revenue USD atau tanpa utang valas |
| **Regulasi baru** | Perubahan aturan main | Update regulasi, adaptasi strategi |

### 9.4 Kendala Teknis

| Kendala | Dampak | Cara Mengatasi |
|---------|--------|----------------|
| **Platform down** | Tidak bisa eksekusi saat pasar ramai | Punya 2 broker sebagai backup |
| **Data tidak akurat** | Analisis salah | Verifikasi data dari multiple sumber |
| **Slippage** | Eksekusi tidak sesuai harga target | Gunakan limit order, bukan market order |
| **Koneksi internet** | Lost connection saat trading | Koneksi backup (mobile data) |

### 11.2 Dampak Biaya pada Return

```
Modal: Rp 100.000.000
Frekuensi trading: 50x setahun (swing trading aktif)
Biaya per keliling: 0.4%
Total biaya setahun: 50 × 0.4% × Rp 100.000.000 = Rp 20.000.000

Return bruto 20% → Rp 20.000.000 profit
Biaya: Rp 20.000.000
Net return: Rp 0 (BREAKEVEN!)

Bandigkan dengan buy & hold:
Frekuensi: 2x setahun (beli & jual setahun kemudian)
Biaya: 2 × 0.4% × Rp 100.000.000 = Rp 800.000
Return bruto 15% → Rp 15.000.000 profit
Biaya: Rp 800.000
Net return: Rp 14.200.000 (14.2%)
```

**Kesimpulan:** Frekuensi trading yang tinggi menggerus return secara signifikan. Pastikan edge trading Anda cukup untuk menutup biaya.

### 13.2 Profit Tracker

```python
class ProfitTracker:
    """Track and analyze profit sources."""
    
    def total_return(self, positions, current_prices):
        """Calculate total return broken down by source."""
        capital_gain = 0
        dividend_income = 0
        total_cost = 0
        
        for pos in positions:
            current_value = pos.shares * current_prices[pos.ticker]
            cost_basis = pos.shares * pos.avg_cost
            capital_gain += current_value - cost_basis
            dividend_income += pos.dividends_received
            total_cost += cost_basis
        
        total_return = capital_gain + dividend_income
        roi = total_return / total_cost if total_cost > 0 else 0
        
        return {
            "capital_gain": capital_gain,
            "dividend_income": dividend_income,
            "total_return": total_return,
            "roi": roi,
            "capital_gain_pct": capital_gain / total_cost if total_cost > 0 else 0,
            "dividend_yield_pct": dividend_income / total_cost if total_cost > 0 else 0,
        }
```

### 13.3 Risk-Adjusted Strategy Optimizer

```python
def optimize_strategy(performance_history, risk_profile):
    """Optimize strategy allocation based on historical performance."""
    # Analyze which strategies performed best
    strategy_returns = {}
    for trade in performance_history:
        strategy = trade.strategy
        if strategy not in strategy_returns:
            strategy_returns[strategy] = []
        strategy_returns[strategy].append(trade.r_multiple)
    
    # Calculate expectancy per strategy
    strategy_expectancy = {}
    for strategy, r_multiples in strategy_returns.items():
        if len(r_multiples) >= 10:  # minimum sample
            avg_win = np.mean([r for r in r_multiples if r > 0]) if any(r > 0 for r in r_multiples) else 0
            avg_loss = np.mean([r for r in r_multiples if r < 0]) if any(r < 0 for r in r_multiples) else 0
            win_rate = sum(1 for r in r_multiples if r > 0) / len(r_multiples)
            expectancy = (win_rate * avg_win) - ((1 - win_rate) * abs(avg_loss))
            strategy_expectancy[strategy] = expectancy
    
    # Allocate more to higher expectancy strategies
    return strategy_expectancy
```

### 16.2 DCA (Dollar Cost Averaging) untuk Retail

```python
def dca_schedule(monthly_amount, tickers, weights):
    """
    Schedule monthly DCA purchases.
    DCA reduces timing risk — buy consistently regardless of market level.
    """
    purchases = []
    for ticker, weight in zip(tickers, weights):
        amount = monthly_amount * weight
        shares = int(amount / current_price(ticker))
        # Round to IDX lot size (100)
        shares = round(shares / 100) * 100
        if shares > 0:
            purchases.append({
                'ticker': ticker,
                'shares': shares,
                'amount': shares * current_price(ticker),
            })
    return purchases
```
