## 1. Klasifikasi Pelaku Pasar Modal

### 1.1 Hierarki Pelaku

```
PELAKU PASAR MODAL
├── A. Pelaku Utama
│   ├── Emiten (Penerbit Efek)
│   ├── Investor (Pembeli Efek)
│   └── Perusahaan Efek (Perantara)
│       ├── Penjamin Emisi Efek (Underwriter)
│       ├── Perantara Pedagang Efek (Broker/Pialang)
│       └── Manajer Investasi
│
├── B. Self-Regulatory Organizations (SRO)
│   ├── Bursa Efek Indonesia (BEI)
│   ├── Kliring Penjaminan Efek Indonesia (KPEI)
│   └── Kustodian Sentral Efek Indonesia (KSEI)
│
├── C. Lembaga Penunjang
│   ├── Kustodian Bank
│   ├── Wali Amanat (Trustee)
│   ├── Biro Administrasi Efek (BAE)
│   ├── Pemeringkat Efek (Rating Agency)
│   └── BAPMI (Badan Arbitrase Pasar Modal Indonesia)
│
├── D. Profesi Penunjang
│   ├── Akuntan Publik
│   ├── Konsultan Hukum
│   ├── Notaris
│   ├── Penilai (Appraiser)
│   └── Profesi lain yang ditetapkan OJK
│
└── E. Regulator
    ├── Otoritas Jasa Keuangan (OJK)
    ├── Bank Indonesia (BI)
    └── Pemerintah (Kemenkeu)
```

### 1.2 Alur Perputaran Modal

```
Emiten (butuh modal)
    ↓ [menerbitkan efek]
Penjamin Emisi (underwrite)
    ↓ [distribusi]
Perantara Pedagang Efek (broker)
    ↓ [jual ke]
Investor (beli efek)
    ↓ [settlement]
KPEI (kliring) → KSEI (penyimpanan)
    ↓ [catat kepemilikan]
Investor (pemilik efek)
```

## 2. Emiten (Penerbit Efek)

### 2.1 Definisi

Emiten adalah pihak yang menerbitkan efek (saham, obligasi, sukuk) untuk dijual kepada publik melalui penawaran umum (IPO) atau penawaran terbatas (private placement). Emiten tercatat di bursa efek.

### 2.2 Tujuan Menjadi Emiten

| Tujuan | Penjelasan |
|--------|-----------|
| **Penghimpunan dana** | Modal untuk ekspansi bisnis, R&D, kapital expenditure |
| **Strukturisasi keuangan** | Pelunasan utang, restrukturisasi balance sheet |
| **Likuiditas pemegang saham** | Pemegang saham dapat menjual saham di pasar sekunder |
| **Valuasi market** | Harga pasar sebagai benchmark valuasi perusahaan |
| **Akuisisi** | Saham sebagai currency untuk akuisisi (stock swap) |
| **Brand & credibility** | Status go-public meningkatkan kredibilitas |
| **ESOP** | Employee Stock Ownership Plan untuk retensi talent |

### 2.3 Kewajiban Emiten

1. **Disclosure berkala:**
   - Laporan keuangan tahunan (diaudit, within 90 hari setelah tahun buku)
   - Laporan keuangan semester (within 60 hari)
   - Laporan keuangan triwulanan (within 45 hari)

2. **Disclosure insidental:**
   - Material information (akuisisi, divestasi, perubahan manajemen)
   - Related party transactions
   - Perubahan anggaran dasar
   - RUPS (Rapat Umum Pemegang Saham)

3. **Tata kelola:**
   - Komisaris independen (minimal 1/3 dari total komisaris)
   - Komite audit
   - Internal audit function
   - Sekretaris perusahaan

4. **Pemenuhan free float:**
   - Minimum 15% saham beredar publik (reformasi 2026)
   - Sebelumnya 7.5-10%

### 2.4 Jenis Emiten

| Jenis | Karakteristik | Contoh |
|-------|--------------|--------|
| **Blue chip** | Kapitalisasi besar, fundamental kuat, likuid | BBCA, BBRI, BMRI, TLKM |
| **Growth** | Pertumbuhan tinggi, valuasi premium | GOTO, BREN, AMMN |
| **Value** | Valuasi murah, dividen tinggi | PGAS, INDY, ITMG |
| **Defensive** | Tahan krisis, konsumer essential | UNVR, ICBP, MYOR |
| **Cyclical** | Bergantung siklus ekonomi | ANTM, INCO, MDKA |
| **Small cap** | Kapitalisasi kecil, likuiditas rendah | Banyak emiten di board Pengembangan |
| **Syariah** | Sesuai prinsip syariah (DES) | BRIS, CMPP, VCID |

### 2.5 Listing Boards di BEI

| Board | Kriteria | Tujuan |
|-------|---------|--------|
| **Utama** | Profitable, kapitalisasi besar, free float tinggi | Perusahaan matang |
| **Pengembangan** | Syarat lebih longgar, boleh belum profit | Perusahaan growth/startup |
| **Akselerasi** | Khusus startup teknologi | Syarat disesuaikan karakter tech |
| **Papan Syariah** | Sesuai prinsip syariah | Investor syariah |

## 3. Investor (Pemodal)

### 3.1 Definisi

Investor adalah pihak yang menginvestasikan dana pada efek (saham, obligasi, reksa dana) dengan tujuan memperoleh return. Investor adalah **provider of capital** — pihak yang menyediakan modal yang dibutuhkan emiten.

### 3.2 Klasifikasi Investor

#### Berdasarkan Entitas

| Jenis | Deskripsi | Contoh |
|-------|-----------|--------|
| **Investor Ritel (Individual)** | Perorangan yang berinvestasi untuk tujuan keuangan pribadi | Karyawan, ibu rumah tangga, profesional |
| **Investor Institusi** | Entitas yang mengelola dana untuk pihak lain | Reksa dana, dana pensiun, asuransi |
| **Investor Asing** | Investor dari luar negeri (institusi maupun ritel) | Global funds, hedge funds, sovereign wealth funds |

#### Berdasarkan Strategi

| Jenis | Deskripsi | Timeframe |
|-------|-----------|-----------|
| **Value Investor** | Mencari saham di bawah nilai intrinsik | Jangka panjang (5-10+ tahun) |
| **Growth Investor** | Mencari perusahaan dengan pertumbuhan tinggi | Jangka menengah-panjang |
| **Income Investor** | Mencari dividen/kupon stabil | Jangka panjang |
| **Trader** | Profit dari pergerakan harga jangka pendek | Jangka pendek (hari-minggu) |
| **Arbitrageur** | Profit dari price discrepancy | Jangka sangat pendek |
| **Index Investor** | Mereplikasi indeks (passive) | Jangka panjang |

#### Berdasarkan Geografi (Indonesia)

| Jenis | Kontribusi | Karakteristik |
|-------|-----------|---------------|
| **Investor domestik ritel** | ~70% jumlah investor, ~30% volume | Emosional, herding, likuiditas tidak stabil |
| **Investor domestik institusi** | ~15% volume | Lebih stabil, fundamental-driven |
| **Investor asing** | ~55% volume (historis) | Fundamental-driven, sensitif global factors |

### 3.3 Investor Institusi — Detail

#### Reksa Dana (Mutual Fund)

- Menghimpun dana dari banyak investor
- Dikelola oleh Manajer Investasi
- Investor membeli unit penyertaan
- **Jenis:** Saham, pendapatan tetap, campuran, pasar uang, indeks, ETF, syariah

#### Dana Pensiun (Pension Fund)

- Mengelola dana pensiun karyawan
- Sebelumnya maksimal 10% di saham, sekarang bisa 20% (reformasi 2026)
- Investor jangka panjang, stabil

#### Asuransi

- Mengelola premi asuransi
- Sebagian dialokasikan ke saham/obligasi
- Investor jangka panjang, risk-averse

#### Sovereign Wealth Fund

- Danantara (Indonesia)
- Mengelola dana negara untuk investasi strategis
- Investor jangka panjang,规模 besar

### 3.4 Investor Terkenal Indonesia

| Nama | Gaya | Catatan |
|------|------|---------|
| **Lo Kheng Hong** | Value investing, multibagger | "Warren Buffett Indonesia" |
| **Andry Hakim** | Value investing, long-term | Investor saham multibagger |
| **Hermawan Tanudjaja** | Value, contrarian | Founder Hermawan Tanudjaja & Partners |

### 3.5 Hak Investor

1. **Hak voting** di RUPS (1 saham = 1 suara, kecuali saham tanpa hak suara)
2. **Hak dividen** sesuai proporsi kepemilikan
3. **Hak pre-emptive** (rights issue) — hak beli saham baru terlebih dahulu
4. **Hak informasi** — akses laporan keuangan dan material information
5. **Hak sue** — gugat pengurus jika merugikan perusahaan (derivative suit)
6. **Hak residual claim** — hak atas aset jika perusahaan likuidasi

## 4. Perusahaan Efek

### 4.1 Definisi

Perusahaan efek adalah perusahaan yang melakukan kegiatan usaha sebagai:
- Penjamin emisi efek (Underwriter)
- Perantara pedagang efek (Broker/Pialang)
- Manajer investasi

Satu perusahaan efek dapat memiliki satu, dua, atau ketiga izin sekaligus.

### 4.2 Penjamin Emisi Efek (Underwriter)

#### Definisi

Pihak yang melakukan kontrak dengan emiten untuk melakukan penawaran umum dengan atau tanpa kewajiban untuk membeli sisa efek yang tidak terjual.

#### Fungsi

1. **Due diligence:** Memverifikasi prospektus, laporan keuangan, legalitas emiten
2. **Pricing:** Menentukan harga IPO yang wajar
3. **Distribusi:** Memasarkan efek ke investor
4. **Stabilization:** Mendukung harga pasca-IPO (green shoe option)
5. **Underwriting commitment:** Membeli sisa efek yang tidak terjual (firm commitment) atau best effort

#### Jenis Underwriting

| Jenis | Deskripsi | Risiko |
|-------|-----------|--------|
| **Firm commitment** | Underwriter beli semua efek dari emiten, lalu jual ke publik | Risiko di underwriter |
| **Best effort** | Underwriter berusaha jual sebanyak mungkin, tidak wajib beli sisa | Risiko di emiten |
| **Standby** | Underwriter siap beli sisa rights issue | Risiko di underwriter |

#### Contoh Perusahaan (Indonesia)

- Mandiri Sekuritas
- BNI Sekuritas
- BCA Sekuritas
- CIMB Niaga Sekuritas
- BRI Danareksa Sekuritas

### 4.3 Perantara Pedagang Efek (Broker/Pialang)

#### Definisi

Pihak yang melakukan perdagangan efek untuk kepentingan sendiri (dealer) atau kepentingan nasabah (broker).

#### Fungsi

1. **Eksekusi order:** Menerima order beli/jual dari investor dan eksekusi di bursa
2. **Market making:** Menyediakan likuiditas (quote bid-ask)
3. **Research:** Memberikan analisis dan rekomendasi saham
4. **Margin lending:** Memberikan pinjaman untuk beli saham (margin trading)
5. **Advisory:** Memberikan nasihat investasi (jika punya izin)

#### Jenis Broker di Indonesia

| Jenis | Karakteristik | Contoh |
|-------|--------------|--------|
| **Full-service** | Research, advisory, margin, IPO access | Mandiri Sekuritas, BNI Sekuritas |
| **Online/discount** | Platform online, biaya rendah, minimal advisory | Ajaib, Stockbit, IPOT |
| **Bank-affiliated** | Terintegrasi dengan bank, akses mudah | BCA Sekuritas, BRI Sekuritas |

#### Persyaratan Pialang

1. Sertifikat **WPEE** (Wakil Perantara Pedagang Efek)
2. Bekerja di perusahaan efek berizin OJK
3. Paham aturan pasar modal
4. Terdaftar di OJK

#### Perbedaan Broker vs Dealer

| Aspek | Broker | Dealer |
|-------|--------|--------|
| **Untuk siapa** | Kepentingan nasabah | Kepentingan sendiri |
| **Posisi** | Perantara (agent) | Principal |
| **Risiko** | Nasabah | Dealer sendiri |
| **Profit** | Komisi | Spread (selisih beli-jual) |

### 4.4 Manajer Investasi

#### Definisi

Pihak yang kegiatan usahanya mengelola portofolio efek untuk nasabah atau mengelola portofolio investasi kolektif untuk sekelompok nasabah.

#### Fungsi

1. **Portfolio management:** Mengelola dana investor untuk maksimalkan return dengan risiko terkontrol
2. **Investment decision:** Memilih saham/obligasi yang akan dibeli/dijual
3. **Risk management:** Mengelola risiko portofolio
4. **Reporting:** Laporan kinerja kepada investor

#### Produk yang Dikelola

- **Reksa dana:** Saham, pendapatan tetap, campuran, pasar uang, indeks
- **Discretionary fund:** Portofolio individual untuk HNWI/institusi
- **ETF:** Exchange Traded Fund

#### Persyaratan

1. Izin usaha Manajer Investasi dari OJK
2. Orang yang menjalankan harus bersertifikat **WMI** (Wakil Manajer Investasi) atau **MI** (Manajer Investasi)
3. Memenuhi requirement modal dan compliance

#### Contoh Manajer Investasi (Indonesia)

- Schroder Investment Management
- Bahana TCW Investment Management
- Ashmore Asset Management
- BNI Asset Management
- Mandiri Investment Management

### 4.5 Penasihat Investasi (Investment Advisor)

#### Definisi

Pihak yang memberikan nasihat kepada emiten atau investor mengenai efek atau hal-hal yang berkaitan dengan efek.

#### Fungsi

1. Memberikan rekomendasi saham/strategi investasi
2. Analisis pasar dan ekonomi
3. Edukasi investor
4. Financial planning

#### Regulasi

- Wajib memiliki sertifikat (CFP, CFA, atau sertifikasi OJK)
- Wajib terdaftar di OJK
- Tidak boleh mengelola dana (itu tugas Manajer Investasi)
- Wajib disclose conflict of interest

## 5. Bursa Efek

### 5.1 Bursa Efek Indonesia (BEI)

#### Definisi

Bursa efek adalah pihak yang menyelenggarakan dan menyediakan sistem perdagangan efek. BEI adalah satu-satunya bursa saham di Indonesia.

#### Fungsi

1. **Menyelenggarakan perdagangan:** Menyediakan platform JATS-NextG
2. **Pencatatan efek:** Mencatat saham/obligasi yang diperdagangkan
3. **Pengawasan perdagangan:** Memantau anomali, manipulasi
4. **Penyebaran informasi:** Publikasi harga, volume, indeks
5. **Self-regulation:** Membuat aturan perdagangan (dengan persetujuan OJK)

#### Struktur BEI

```
PT Bursa Efek Indonesia (Persero)
├── Dewan Komisaris
├── Direksi
│   ├── Direktur Utama
│   ├── Direktur Perdagangan dan Pengawasan Anggota Bursa
│   ├── Direktur Pengembangan Bisnis
│   └── Direktur Hukum dan Kepatuhan
├── Divisi Perdagangan
├── Divisi Pengawasan
├── Divisi Pencatatan
├── Divisi Teknologi
└── Divisi Hukum & Compliance
```

#### Indeks yang Dikelola BEI

| Indeks | Deskripsi |

| **IHSG (Composite)** | Indeks utama, semua saham tercatat |

## 6. Lembaga Kliring dan Penjaminan

### 6.1 KPEI (Kliring Penjaminan Efek Indonesia)

#### Definisi

Lembaga yang menyelenggarakan jasa kliring dan penjaminan penyelesaian transaksi bursa yang teratur, wajar, dan efisien.

#### Fungsi

1. **Kliring:** Menghitung hak dan kewajiban setiap anggota bursa dari transaksi
2. **Penjaminan:** Menjamin penyelesaian transaksi (counterparty risk mitigation)
3. **Risk management:** Mengelola risiko default anggota bursa
4. **Margin system:** Mengelola margin dan jaminan

#### Mekanisme Kliring

```
Transaksi di BEI
    ↓
KPEI menghitung net position per anggota
    ↓
KPEI menjamin penyelesaian (novation)
    ↓
Penyelesaian via KSEI (T+2)
```

#### Novation

KPEI melakukan **novation** — menggantikan counterparty asli dengan KPEI sebagai counterparty. Artinya, jika pihak A beli dari pihak B, setelah novation:
- A berhak atas efek dari KPEI (bukan dari B)
- B berhak atas dana dari KPEI (bukan dari A)
- Jika B default, KPEI tetap bayar ke A

Ini menghilangkan counterparty risk untuk investor.

## 7. Lembaga Penyimpanan dan Penyelesaian

### 7.1 KSEI (Kustodian Sentral Efek Indonesia)

#### Definisi

Lembaga yang menyelenggarakan kegiatan kustodian sentral bagi bank kustodian, perusahaan efek, dan pihak lain.

#### Fungsi

1. **Penyimpanan efek:** Menyimpan efek dalam bentuk elektronik (scripless)
2. **Penyelesaian transaksi:** Transfer kepemilikan efek antar investor
3. **Pencatatan kepemilikan:** Mencatat siapa pemilik efek
4. **Korporasi efek:** Memproses dividen, stock split, rights issue
5. **Data kepemilikan:** Menyediakan data kepemilikan untuk transparansi

#### Sistem KSEI

```
C-BEST (C-Best Electronic Settlement Transfer)
├── Rekening efek per investor (sub-rekening)
├── Transfer antar rekening (settlement)
├── Pencatatan korporasi efek
└── Pelaporan kepemilikan
```

#### Scripless Trading

Di Indonesia, semua efek dalam bentuk **scripless** (elektronik, tanpa sertifikat fisik). KSEI menjadi pusat pencatatan kepemilikan.

### 7.2 Bank Kustodian

#### Definisi

Bank yang menyimpan dan mengelola efek untuk investor institusional.

#### Fungsi

1. **Safekeeping:** Menyimpan efek
2. **Administration:** Mengelola dividen, coupon, corporate actions
3. **Settlement:** Menyelesaikan transaksi
4. **Reporting:** Laporan kepemilikan dan transaksi

#### Perbedaan KSEI vs Bank Kustodian

| Aspek | KSEI | Bank Kustodian |
|-------|------|----------------|
| **Skala** | Sentral (semua efek Indonesia) | Per institusi |
| **Klien** | Perusahaan efek, bank kustodian | Investor institusi |
| **Fungsi** | Pencatatan sentral | Safekeeping & admin |
| **Izin** | LPP (Lembaga Penyimpanan & Penyelesaian) | Bank dengan izin kustodian |

## 8. Lembaga Penunjang Pasar Modal

### 8.1 Wali Amanat (Trustee)

#### Definisi

Pihak yang mewakili kepentingan pemegang efek (investor) dalam penerbitan efek bersifat utang (obligasi, sukuk).

#### Fungsi

1. Mewakili investor dalam memastikan emiten memenuhi kewajiban
2. Memantau compliance emiten dengan kontrak efek
3. Mengambil tindakan hukum jika emiten default
4. Menerima dan mendistribusikan pembayaran kupon/pokok

### 8.2 Biro Administrasi Efek (BAE)

#### Definisi

Pihak yang menyelenggarakan administrasi efek untuk emiten.

#### Fungsi

1. Mencatat pemindahan kepemilikan efek
2. Mengelola pembayaran dividen/kupon
3. Menerbitkan sertifikat efek (jika diperlukan)
4. Menyimpan daftar pemegang efek

### 8.3 Pemeringkat Efek (Rating Agency)

#### Definisi

Lembaga yang memberikan peringkat (rating) atas efek bersifat utang (obligasi, sukuk).

#### Fungsi

1. Menilai kemampuan emiten membayar utang
2. Memberikan rating (AAA, AA, A, BBB, etc.)
3. Memantau dan memperbarui rating secara berkala

#### Contoh Pemeringkat di Indonesia

- PEFINDO (Pemeringkat Efek Indonesia)
- Fitch Ratings Indonesia
- ICRA Indonesia

#### Skala Rating

```
Investment Grade:
  AAA  → Kualitas tertinggi, risiko default terendah
  AA   → Kualitas sangat tinggi
  A    → Kualitas tinggi
  BBB  → Kualitas cukup (lowest investment grade)

Non-Investment Grade (Speculative/Junk):
  BB   → Speculative, risiko moderate
  B    → Speculative, risiko tinggi
  CCC  → Speculative, risiko sangat tinggi
  CC   → Sangat spekulatif
  C    → Sangat spekulatif, mendekati default
  D    → Default
```

### 8.4 BAPMI (Badan Arbitrase Pasar Modal Indonesia)

#### Definisi

Lembaga yang menangani sengketa antara pelaku pasar modal melalui arbitrase.

#### Fungsi

1. Menyelesaikan sengketa antara investor dan perusahaan efek
2. Arbitrase yang lebih cepat dari pengadilan umum
3. Putusan bersifat final dan mengikat

## 9. Profesi Penunjang Pasar Modal

### 9.1 Akuntan Publik

#### Definisi

Akuntan independen yang memberikan jasa audit atas laporan keuangan emiten.

#### Fungsi

1. **Audit laporan keuangan:** Memeriksa apakah laporan keuangan wajar sesuai standar akuntansi (PSAK/IFRS)
2. **Memberikan opini audit:**
   - **Unqualified opinion (Wajar tanpa pengecualian)** — terbaik
   - **Qualified opinion (Wajar dengan pengecualian)** — ada masalah terbatas
   - **Adverse opinion (Tidak wajar)** — laporan menyesatkan
   - **Disclaimer of opinion** — tidak dapat memberikan opini
3. **Review laporan keuangan interim**
4. **Agreed-upon procedures:** Prosedur khusus atas permintaan OJK/emiten

#### Regulasi

- Wajib terdaftar di OJK
- Wajib mengikuti standar audit (PSA)
- Rotasi auditor (tidak boleh audit emiten yang sama > 5 tahun berturut-turut untuk partner)
- Independence requirement (tidak boleh ada conflict of interest)

### 9.2 Konsultan Hukum

#### Definisi

Ahli hukum yang memberikan jasa konsultasi hukum terkait pasar modal.

#### Fungsi

1. **Legal opinion:** Memberikan pendapat hukum atas emiten dan efek yang diterbitkan
2. **Due diligence hukum:** Memeriksa legalitas perusahaan, kontrak, litigasi
3. **Prospektus review:** Memastikan prospektus tidak melanggar hukum
4. **Compliance:** Memastikan emiten mematuhi regulasi pasar modal

#### Regulasi

- Wajib terdaftar di OJK
- Wajib anggota HKHPM (Himpunan Konsultan Hukum Pasar Modal)
- Memenuhi persyaratan pengalaman dan kompetensi

### 9.3 Notaris

#### Definisi

Pejabat umum yang berwenang membuat akta otentik.

#### Fungsi di Pasar Modal

1. **Akta pendirian/perubahan anggaran dasar** emiten
2. **Akta RUPS** (Rapat Umum Pemegang Saham) dan RUPSLB
3. **Akta perjanjian** terkait penerbitan efek
4. **Berita acara** rapat direksi/komisaris
5. **Menghadiri RUPS** dan menyiapkan berita acara

#### Regulasi

- Wajib terdaftar di OJK untuk kegiatan pasar modal
- Memahami UU Pasar Modal dan POJK terkait

### 9.4 Penilai (Appraiser)

#### Definisi

Pihak yang memberikan jasa profesional dalam menentukan nilai wajar aktiva suatu perusahaan.

#### Fungsi

1. **Penilaian aset:** Menilai nilai wajar aset tetap, tanah, bangunan, mesin
2. **Penilaian bisnis:** Menilai nilai perusahaan untuk IPO/M&A
3. **Penilaian agunan:** Menilai agunan untuk penerbitan obligasi
4. **Laporan penilaian:** Menerbitkan laporan dengan standar yang ditetapkan

#### Regulasi

- Wajib terdaftar di OJK
- Wajib anggota MAPPI (Masyarakat Profesi Penilai Indonesia)
- Mengikuti standar penilaian Indonesia (SPI)

### 9.5 Profesi Lainnya

| Profesi | Fungsi |
|---------|--------|
| **Aktuaris** | Menghitung nilai aktuarial untuk penerbitan obligasi/asuransi |
| **Konsultan Pajak** | Memberikan opini perpajakan untuk emiten |
| **Ahli Teknik** | Memberikan opini teknis untuk emiten industri/manufaktur |
| **Environmental Consultant** | Penilaian dampak lingkungan untuk ESG disclosure |

## 10. Regulator dan Pengawas

### 10.1 OJK (Otoritas Jasa Keuangan)

#### Definisi

Lembaga negara yang mengatur dan mengawasi kegiatan di sektor jasa keuangan, termasuk pasar modal.

#### Kewenangan

1. **Regulasi:** Membuat peraturan (POJK) untuk pasar modal
2. **Perizinan:** Memberikan izin kepada pelaku pasar modal
3. **Pengawasan:** Memantau kegiatan pelaku dan emiten
4. **Penegakan:** Menjatuhkan sanksi atas pelanggaran
5. **Perlindungan investor:** Edukasi, SIPF, whistleblower system

#### Struktur OJK Pasar Modal

```
OJK
└── Dewan Komisioner
    └── Eksekutif Pengawas Pasar Modal, Keuangan Derivatif, dan Bursa Karbon
        ├── Direktorat Pengawasan Pasar Modal I
        ├── Direktorat Pengawasan Pasar Modal II
        ├── Direktorat Pengawasan Perusahaan Efek
        ├── Direktorat Pengawasan Emiten
        ├── Direktorat Pengawasan Transaksi dan Produk
        └── Direktorat Penilaian dan Sanksi
```

### 10.2 Bank Indonesia (BI)

#### Peran di Pasar Modal

1. **Suku bunga acuan:** BI Rate mempengaruhi cost of capital dan valuasi saham
2. **Rupiah:** Kebijakan moneter mempengaruhi nilai tukar → investor asing
3. **Sistem pembayaran:** Penyelesaian transaksi pasar modal dalam Rupiah
4. **Makroprudential:** Kebijakan makroprudential mempengaruhi sektor perbankan

### 10.3 Pemerintah (Kemenkeu)

#### Peran

1. **Kebijakan fiskal:** Pajak, stimulus, belanja negara
2. **Surat berharga negara:** SBN (SBR, ORI, Sukuk) sebagai benchmark
3. **BUMN:** BUMN yang go-public tunduk pada kebijakan pemerintah
4. **UU Pasar Modal:** Inisiatif perubahan undang-undang

### 10.4 SRO (Self-Regulatory Organizations)

SRO adalah organisasi yang diberi kewenangan oleh OJK untuk membuat dan menegakkan aturan sendiri:

| SRO | Kewenangan |
|-----|-----------|
| **BEI** | Aturan perdagangan, pencatatan emiten, pengawasan anggota bursa |
| **KPEI** | Aturan kliring dan penjaminan, margin system |
| **KSEI** | Aturan penyimpanan dan penyelesaian, kustodian |

## 12. Interaksi Antar Pelaku

### 12.1 Alur IPO (Primary Market)

```
1. Emiten memutuskan go-public
2. Emiten menunjuk:
   ├── Penjamin Emisi (Underwriter)
   ├── Akuntan Publik (audit laporan keuangan)
   ├── Konsultan Hukum (legal opinion)
   ├── Notaris (akta-akta)
   ├── Penilai (nilai aset, jika perlu)
   └── Pemeringkat Efek (rating obligasi, jika obligasi)
3. Due diligence oleh penjamin emisi + profesi penunjang
4. Penyusunan prospektus
5. Pendaftaran ke OJK (izin penawaran umum)
6. Book building (menentukan harga IPO)
7. Penawaran umum (public offering)
   ├── Perantara Pedagang Efek mendistribusi ke investor
   └── Investor menempatkan order
8. Alokesai saham
9. Pencatatan di BEI
10. Penyelesaian via KPEI → KSEI
11. Investor menerima saham di rekening KSEI (sub-rekening via perusahaan efek)
```

### 12.2 Alur Trading (Secondary Market)

```
1. Investor menempatkan order via Perusahaan Efek (broker)
2. Broker mengirim order ke BEI (JATS-NextG)
3. BEI mencocokkan order (matching) → transaksi
4. KPEI menghitung net position (kliring)
5. KPEI menjamin penyelesaian (novation)
6. KSEI transfer kepemilikan efek (T+2)
7. Investor menerima efek di rekening KSEI
8. Investor membayar (via RDN - Rekening Dana Nasabah di bank)
```

### 12.3 Alur Dividen

```
1. Emiten menyatakan dividen di RUPS
2. Emiten memberitahu KSEI (record date / cum-div date)
3. KSEI mengidentifikasi pemegang saham pada record date
4. Emiten transfer dana ke KSEI
5. KSEI distribusi dividen ke perusahaan efek
6. Perusahaan efek distribusi ke RDN investor
```

### 13.2 Klasifikasi Investor dalam Aplikasi

```python
class InvestorClassifier:
    """Classify investor type for personalized features."""
    
    def classify(self, profile):
        investor_type = []
        
        # By entity
        if profile.is_individual:
            investor_type.append("RETAIL")
        else:
            investor_type.append("INSTITUTIONAL")
        
        # By strategy
        if profile.timeframe == "long" and profile.focus == "value":
            investor_type.append("VALUE")
        elif profile.timeframe == "short":
            investor_type.append("TRADER")
        elif profile.focus == "dividend":
            investor_type.append("INCOME")
        
        # By risk tolerance
        if profile.risk_tolerance == "low":
            investor_type.append("CONSERVATIVE")
        elif profile.risk_tolerance == "high":
            investor_type.append("AGGRESSIVE")
        
        return investor_type
```

### 13.3 Broker Flow Analysis

```python
def analyze_broker_concentration(broker_data):
    """Analyze broker concentration for manipulation detection."""
    # High concentration = potential coordinated trading
    top_3_volume = sum(broker_data.nlargest(3, 'volume')['volume'])
    total_volume = broker_data['volume'].sum()
    concentration_ratio = top_3_volume / total_volume
    
    if concentration_ratio > 0.5:
        return {"alert": "HIGH_BROKER_CONCENTRATION", "ratio": concentration_ratio}
    return {"alert": None, "ratio": concentration_ratio}
```

### 13.4 Foreign Flow Tracking

```python
def foreign_flow_signal(foreign_data, ticker):
    """Generate signal from foreign flow data."""
    net_30d = foreign_data[ticker]['net_30d']
    net_90d = foreign_data[ticker]['net_90d']
    
    if net_30d > 0 and net_90d > 0:
        return "FOREIGN_ACCUMULATION"
    elif net_30d < 0 and net_90d < 0:
        return "FOREIGN_DISTRIBUTION"
    elif net_30d < 0 and net_90d > 0:
        return "FOREIGN_PROFIT_TAKING"
    else:
        return "FOREIGN_MIXED"
```
